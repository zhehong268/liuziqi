# AI 接入

人机练习和上传示例的算法在 `bot.py`，官方 AI 在 `official/main.cpp`，复盘在 `agent.py`。它们都不需要 API Key。网页上传协议与限制见 [上传 AI 与对战](上传AI与对战.md)。

## 改下棋算法

修改 `choose_ai_move(board, player)`。输入和返回值约定如下：

| 参数 | 格式 |
| --- | --- |
| `board` | 19×19 列表，空位为 `None`，棋子为 `"black"` 或 `"white"` |
| `player` | 当前执棋颜色 |
| 返回值 | `(row, col)`，0～18 的整数，对应一个空位 |

当前算法先找自己能直接成六的位置，再找对手能直接成六的位置，最后对其余空位打分。评分用到了己方连线、对手连线、邻居数量和中心距离。

`winning_cells()` 会临时放一颗棋检查是否成六，检查完恢复棋盘。`choose_ai_move()` 返回位置后，才由后端校验并保存。

一个容易开始的改动是调整 `score()` 的进攻、防守权重。改完重启 `app.py`，用同样的开局比较落点。更多算法可以继续写在 `bot.py` 内，方便保持单文件提交。

## Web 和平台怎么调用

Web 的调用顺序：

```text
POST /api/games/<id>/ai-turn
  → choose_agent_move(board, "white", "local")
  → choose_ai_move(board, "white")
  → place_one() 保存落子
```

平台调用 `bot.py` 的 `main()`。它逐行读 stdin，把请求交给 `decide()`；后者将 0/1/2 棋盘转成策略函数使用的格式，再返回落点。

每次只下一颗。第二颗由后端或平台裁判再次调用，行动方读取 `observation.current_player`，不能按请求次数的奇偶判断。

## 复盘 Agent

`local_analysis()` 按棋谱重建每一步局面。在复盘方一个完整回合结束后，检查对手有没有用一颗或两颗子成六的窗口，记录手数、威胁坐标和建议。人机练习默认分析黑方，AI 挑战按上传方实际颜色分析。开局偏边也会给出布局建议。

只在完整回合后检查，是因为第一颗暂时没封堵，第二颗仍可能补上。

结果包含以下字段，前端据此显示复盘：

| 字段 | 内容 |
| --- | --- |
| `summary` | 棋局概况 |
| `keyMistakes` | 手数、原因、建议 |
| `strengths` | 检测到的正面观察 |
| `nextPractice` | 练习建议 |
| `trace` | 执行步骤 |

这是固定流程的规则分析，暂时不搜索多回合战术。结果按棋局和落子数量写入 `analyses`，相同棋谱复用已有结果。

## 可选外部模型

平台提交的 `bot.py` 不使用这一部分。想在 Web 中试外部模型时：

```powershell
Copy-Item .env.example .env
notepad .env
```

填写配置并重启后端：

| 配置 | 说明 |
| --- | --- |
| `OPENAI_API_KEY` | 服务商提供的 Key |
| `OPENAI_MODEL` | 账号可调用的模型 ID |
| `OPENAI_BASE_URL` | 服务商的 API 基础地址；OpenAI 官方可留空 |
| `AI_API_STYLE` | `responses` 或 `chat`，按服务商支持的接口选择 |
| `AI_TIMEOUT_SECONDS` | 每颗棋子的模型请求超时，默认 20 秒 |

Responses 使用 JSON Schema，Chat Completions 使用 JSON mode。实现见 `call_model_json()`。接口不兼容或返回值无效时会使用本地规则，页面显示回退原因。

刷新页面后选择“大模型 AI · 已配置”，新建一局。配置 Key 后，未缓存的复盘也会调用模型。一次 AI 回合最多请求两次，终局复盘另有一次请求；棋盘和棋谱会发送到所配置的服务，按服务商规则计费。`.env` 不要提交到 Git。

清空 Key 并重启后端即可关闭。配置后用新棋局测试，旧棋谱会继续显示已保存的结果。当前外部接口只做了模拟测试，还没用真实 Key 调用。

接口参考：[Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses)、[Chat Completions](https://developers.openai.com/api/reference/python/resources/chat/subresources/completions/methods/create)。

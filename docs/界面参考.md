# 界面参考

背景来自王希孟《千里江山图》局部：[Wikimedia Commons 文件页](https://commons.wikimedia.org/wiki/File:Wang_Ximeng_-_A_Thousand_Li_of_River1.jpg)。该页标记为公有领域（Public Domain）。项目裁切、提亮并降低饱和度后保存为 `static/qianli-background.webp`，页面不用连接外部图片站。

棋盘的灰白纸面、墨线与棋子由项目 SVG 和 CSS 绘制。参考看了 [水墨围棋盘](https://www.pngsucai.com/png/8963930.html) 和 [Goban3D 的黑白盘面](https://goban3d.com/images/screenshots/mac-high-contrast-light.jpg)。

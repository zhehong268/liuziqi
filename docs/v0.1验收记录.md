## 自动测试

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
node --check static/app.js
```

- 首回合与双子回合、四方向六连和超过六子的连线。

- AI 自我对弈、`arena.v1` 常驻进程连续处理请求。
- 外部模型接口的模拟返回、非法结果和失败回退。

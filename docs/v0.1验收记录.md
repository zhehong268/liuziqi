## 已完成并验证

- [x] 棋种符合平台：六子棋，19×19、首回合一颗、之后每回合两颗。
- [x] 四方向六连及超过六子判胜，第一颗获胜立即结束。
- [x] 前端可以下棋，白方由自编 Python AI 自动应手。

- [x] SQLite 保存对局与逐颗棋谱；旧数据库迁移不丢对局。

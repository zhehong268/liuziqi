网页练习：[打开墨弈](https://zhehong268.github.io/liuziqi/)。

Windows 10 / 11，64 位：

1. 下载 MoYi-Setup-Windows-x64.exe 安装；也可以解压 MoYi-Portable-Windows-x64.zip，运行里面的 MoYi.exe。
2. 打开后会自动进入本机棋局，人机练习不需要额外安装 Python 或填写 API Key。
3. 要上传 Python / C++ AI 挑战官方版，先安装并启动 Docker Desktop（Linux 容器），再点启动窗口的“准备对战环境”。第一次会下载镜像，需要联网。
4. 环境就绪后，从网页上传源码，选择先后手并开始挑战。每颗子 10 秒，单线程。

对局、上传的 AI 和复盘记录保存在 %LOCALAPPDATA%\MoYi\data。更新或卸载程序不会自动删除这些记录。

程序未购买代码签名证书；Windows 可能提示无法验证发布者。请从本仓库下载，并用 SHA256SUMS.txt 核对文件。
